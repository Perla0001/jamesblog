# James en Corea

Aplicación web desarrollada con Python y Django.

## Tecnologías

- Python
- Django
- PostgreSQL
- Ubuntu Server
- Apache
- mod_wsgi

## Módulos principales

- Usuarios
- Vlogs
- Skincare
- Coreano

## Despliegue

La aplicación fue desplegada en Ubuntu Server y configurada con Apache, utilizando PostgreSQL como motor de base de datos.
